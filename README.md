<h1>PalChat</h1>
<h2>Description</h2>
<p> <b>PalChat</b> is a real-time messaging application, it was built using Flutter for the front end and Django for the backend. <br>
  Django REST Framework handles all logic through REST APIs, while Django Channels manages real-time messaging with WebSockets. MySQL is used as the database for storing user data and messages.  </p>
